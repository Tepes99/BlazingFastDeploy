# Future roadmap

Possible later work includes explicit backups, PostgreSQL support, richer health policies, deployment event history, stronger privilege separation, and carefully designed multi-server support. Provider provisioning, Route 53 automation, registries, CI/CD, private networking, queues, workers, object storage, monitoring platforms, metrics, and a browser interface are deliberately absent from version one.

These features should be added only for a concrete need. The current extension boundaries are the local command runner, SSH transport, manifest parser, remote lifecycle helper, state document, and privileged Caddy helper.
